# LeetCode Solutions

My solutions to [LeetCode](https://leetcode.com/) problems

## Overview

This repository contains my personal solutions to LeetCode problems, written as I practice data structures, algorithms, and problem-solving techniques.

## Structure

```
leetcode/
├── array/
│   ├── 001-two-sum/
|   |   ├── solution.java
│   │   └── README.md
│   └── ...
├── linked-list/
├── dynamic-programming/
├── trees/
├── graphs/
└── ...
```

Each solution folder typically includes:
- The solution file (e.g. `solution.py`, `Solution.java`, `solution.cpp`)
- A short README.md with the problem link, approach, and complexity analysis

## Languages Used

- Python
- Java
- C

## Notes

- Solutions prioritize clarity first, then optimization.
- Time and space complexity are noted in each problem's README when relevant.
- This repo is a personal learning log — solutions may be revisited and improved over time.
